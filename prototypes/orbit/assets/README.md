# 图标来源

`bilibili.svg`、`tiktok.svg`、`x.svg`、`xiaohongshu.svg`、`taobao.svg` 来自 Simple Icons 14.14.0，图标数据按 CC0 1.0 提供，许可原文见 SIMPLE-ICONS-LICENSE.md。

原始固定版本路径：`https://cdn.jsdelivr.net/npm/simple-icons@14.14.0/icons/<名称>.svg`。嵌入应用时转换为白色单色标识，使用对应品牌色底。

`jd.ico` 来自京东官方网站 `https://www.jd.com/favicon.ico`，保留原图。上述图标和商标的权利属于相应所有者；Simple Icons 的 CC0 不授予商标权，也不覆盖京东文件。

拼多多和额外演示候选项使用文字/符号回退。所有资源通过 app-assets.js 内的数据 URI 使用，预览运行时不访问这些来源。
