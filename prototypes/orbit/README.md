# 星环首页交互预览

用现代浏览器打开 `index.html`，或打开单文件 `SevenDays-Orbit-Preview.html`。无需账号或联网，Three.js 0.160.0 与图标均已随文件提供。这是示例数据驱动的独立预览；Android 0.6.3 使用 native-home 变体接入真实数据。

## 空间与信息层级

- 中央是小型星球与内侧装饰环，应用卡片位于独立的外侧轨道。两者之间预留几何间距，不依赖提高绘制顺序遮盖穿模。
- 卡片改为圆角应用胶囊；靠前显示图标与名称，背面仅显示图标。完整每日额度、剩余时间、用量和锁定日期放在下方的选中卡片。
- 卡片正反面使用不透明、开启深度测试和深度写入的材质，避免透明平面排序导致的闪烁或切片。绘制纹理铺满画布，圆角由真实几何裁切。
- 1–7 个应用均匀分布在完整圆周，经过背面接缝时连续运动。超过 7 个应用使用固定间距的滑动窗口，在后方缩小退出；几何池固定为 7 个卡片组，纹理 LRU 缓存上限为 18。
- 标题、数字、按钮和留白统一；今日总用量由示例数据计算。无口号、劝导文案或应用内动效开关。

## 交互

- 横向或纵向滑动转动，松手后按末段速度惯性减速。点按运动中的轨道立即刹停，保留当前位置；该次点按不会同时打开详情。
- 停稳后点击应用胶囊进行选择，点击已选胶囊或下方用量卡片打开详情。
- 上/下一个按钮、方向键和「全部应用」列表提供准确选择。一个应用时禁用无意义的旋转操作。
- 首页主题名与设置中的「外观主题」打开同一个选择面板。土星环、星轨、极光改变实际环带结构和完整界面配色。
- 浏览器允许本地存储时，使用 `sevendays.orbit.appearance.v1` 记住主题；切换保留选中应用、角度与示例额度。拒绝本地存储时仍可正常使用。
- 添加应用只加入预览，刷新后恢复示例。预览没有真实授权、计时、后台服务或 Android 数据桥接。
- 适配系统深色和减少动态效果；停稳、页面隐藏或离开可见区域后不持续渲染。WebGL 不可用时使用透视卡片降级布局，保留选择与主题切换。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html`、`styles.css` | 页面结构与产品样式 |
| `scene.js` | 示例数据、选择、手势、面板、主题存储 |
| `orbit-renderer.js` | 卡片几何、固定数量复用、纹理缓存、命中检测、降级布局 |
| `planet-themes.js` | 星球、三套环带、材质与缩略预览 |
| `app-assets.js` | 嵌入图标与画布绘制；不发起网络请求 |
| `assets/` | 图标源文件、许可和来源记录 |
| `three.min.js`、`THREE-LICENSE.txt` | Three.js 0.160.0 与 MIT 许可 |
| `build-preview.py` | 从源码生成离线单文件 |
| `checks/` | 浏览器交互、几何间距、接缝连续性检查脚本 |

运行 `python3 build-preview.py` 重建单文件。浏览器检查需要 Node.js、Playwright 和 Chromium；可通过 `BROWSER_EXECUTABLE` 指定现有 Chromium，通过 `FONTCONFIG_FILE` 指定包含中文字体的 Fontconfig 配置。检查会在 `check-results/` 写出记录与本地 QA 截图，截图不属于交付文件。

```sh
node checks/continuity.cjs
node checks/geometry.cjs
node checks/browser.cjs
```

验证范围和限制见项目的 `docs/ORBIT-REFINEMENT.md`。Android 0.6.3 已通过 native-home 控制器读取原有数据库的真实快照；这里的演示 `apps` 数组不会进入 APK。

顶部短横条现在具有 44px 拖动区域；正文独立滚动，标题和关闭按钮保持可见。轻触不关闭，短拖回弹，明显下拉或快速下滑关闭；触摸取消和横移不触发关闭。共同控制器在 sheet-motion.js，按系统减少动态效果设置处理返回和退出。
